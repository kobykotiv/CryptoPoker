# Bitcoin Poker

## Overview
Bitcoin Poker is an innovative poker platform that integrates Bitcoin Lightning Network technology to provide secure, fast, and low-cost poker games. This platform allows players to participate in poker games using Bitcoin as the currency, leveraging the advantages of the Lightning Network for instant microtransactions.

## Features
- **Secure Transactions**: Utilizes Bitcoin Lightning Network for secure and private transactions
- **Low Fees**: Minimal transaction fees compared to traditional payment methods
- **Instant Settlements**: Real-time payouts and game settlements
- **Decentralized Authentication**: No need for traditional KYC procedures
- **Provably Fair Gaming**: Transparent algorithms ensure game integrity
- **Multiple Game Variants**: Supports Texas Hold'em, Omaha, and other popular poker variants
- **Tournament Support**: Both Sit-n-Go and scheduled tournament formats
- **Mobile Responsive**: Play from any device with a responsive design

## Getting Started

### Prerequisites
- Node.js v14.0.0 or higher
- Bitcoin Lightning Network node (LND, c-lightning, or Eclair)
- MongoDB v4.2 or higher

### Installation
1. Clone the repository:
```
git clone https://github.com/yourusername/bitcoin-poker.git
cd bitcoin-poker
```

2. Install dependencies:
```
npm install
```

3. Configure environment variables:
```
cp .env.example .env
```
Then edit `.env` with your specific configuration.

4. Run the application:
```
npm start
```
